# 快速决策

AstrBot 插件，使用官方**判断提供商**统一决定：要不要说话、用怎样的回复策略，以及要不要从「表情包管理器」图库按描述配一张表情包。面向 QQ（`aiocqhttp`）的群聊和私聊。

支持 AstrBot `>=4.29.4,<5`，无需额外 Python 依赖，采用 [MIT 许可证](LICENSE)。表情包管理器为可选插件；未安装时仍可使用文字回复与自定义判断。

> 必须先在 WebUI「模型提供商 → 判断」中配置 System One 判断提供商，本插件才能完整工作。未配置或调用失败时不会用聊天模型顶替判断提供商。

## 功能概要

- 群聊：即使被 @ 或引用，也由判断模型决定是否回复，可以不回。群聊被动判断为 `none` / `reply` 二选一：`reply` 同时覆盖针对某条消息回复和自然参与讨论 / 插话，不强制引用。是否出现引用气泡仍由「判断发言后直接在群里发送」开关和目标消息选择决定。
- 私聊：收到消息默认回复；判断模型会询问你配置的自定义问题（默认包括回复长短），以及是否配图、选哪张图。
- 支持群聊插话，以及群聊 / 私聊在沉默一段时间后主动开口。沉默时长只触发一次评估，是否发言仍由判断模型决定。
- 可为判断模型填写一段**自定义上下文**（例如机器人名字、群内身份），只进入判断模型的 `state.custom_context`，不会传给会话模型。留空则不附加。
- 可编辑或新增判断问题（选择题或是否题），为每个结果设置选择权重和「告诉会话模型的内容」。支持温度采样，让概率略低的选项也有机会被选中。生成回复时，所有非空提示会拼进临时的 `<quick_decision>` 标签，不写入之后的聊天记录。没有可用提示时不注入。
- 是否发言、回复哪一条、是否配表情以及选哪张图仍由插件内置，不能用自定义问题覆盖。
- 只支持纯文字，或先发文字、再另发一条独立表情包（同一条气泡里不会图文混排），不包含语音。
- 私聊和普通 @ 仍放行官方默认主 Agent；群聊未 @ 插话，以及 debounce 合并后的入站生成，改为 `yield event.request_llm(..., conversation=当前会话)` 进入同一套官方主 Agent（压缩、完整人格 / Skill / 工具、request/response 与装饰 / after-send 钩子、官方历史与 token 统计）。不要把 `llm_generate` 或 `tool_loop_agent` 当成完整官方聊天。官方 `segmented_reply`（含 regex 与间隔）由 RespondStage 执行；表情在全部文字成功发出后再另发一条。冷场主动没有入站事件，本版本仍自行调用聊天模型，不宣称已接入官方 Agent。
- 表情包图库与描述由市场插件「表情包管理器」（`anka-afk/astrbot_plugin_meme_manager`）管理。本插件在判断时只读取候选描述并精确选中对应文件，不看原图像素，也不再提供自制图库的上传、删除或自动描述入口。
- 官方联动 API（如 `compat_send_message` / `compat_prepare_message`）按分类标记发送，会在分类内随机取图，因此本插件不使用它们选图，而是读取管理器存储协议中的 `semantic_metadata.json` 逐图描述来建立候选并按 id 取文件。缺依赖时只发文字，并给出提示，不会回退到旧自制图库。
- 为避免两个插件各发一张图，请在表情包管理器中关闭「启用主动发送表情工具」，并把「表情发送概率」设为 0。不要同时打开管理器的自动配图。
- 判断模型与主会话模型分开使用上下文：判断只用自定义上下文、插件整理的精简近期聊天、是否被 @ / 引用，以及表情描述列表，不注入角色提示词、角色扮演 Skill 或官方完整上下文。入站文字生成走官方主 Agent 的原有注入；判断得到的会话提示放在临时 `<quick_decision>` 块中，不会写入长期历史。
- 决策进行中到达的新消息会并入同一轮，避免连续多次回复。
- 试运行模式只记录决策，不向 QQ 发送因决策产生的消息，也不会放行官方默认回复。

请不要同时开启官方「概率主动回复」。本插件不依赖其它读空气插件。

## 安装与重载

1. 本仓库已公开，可直接在 AstrBot WebUI 的「插件」页选择「从链接安装」，填入仓库地址：

   ```text
   https://github.com/MartinXProMax/astrbot_plugin_quick_decision
   ```

   也可[下载仓库 ZIP](https://github.com/MartinXProMax/astrbot_plugin_quick_decision/archive/refs/heads/main.zip)，再通过「从文件安装」上传。解压后的插件根目录须包含 `metadata.yaml`。

2. 在 WebUI「模型提供商 → 判断」配置 System One 判断提供商。
3. 如需配表情包，安装并启用[表情包管理器](https://github.com/anka-afk/astrbot_plugin_meme_manager)，在其页面管理图库和逐图描述。关闭其「启用主动发送表情工具」，并把「表情发送概率」设为 0，避免重复配图。
4. 关闭 AstrBot 官方「概率主动回复」，避免重复发言。
5. 按需在插件配置中调整群聊 / 私聊开关、冷场时长、冷却、阈值和温度，或在插件详情页「判断配置」中编辑自定义上下文、问题及选项权重。建议先开启「试运行模式」检查决策日志。
6. 更新代码后，在 WebUI「插件」页找到「快速决策」，点击卡片上的刷新图标进行**重载**。如果出现在「加载失败插件」列表，在该列表中点击「重载」并查看日志。

如需手动部署，也可以将本目录完整复制到 AstrBot 数据目录的插件文件夹，例如容器内：

```bash
cp -a astrbot_plugin_quick_decision /AstrBot/data/plugins/
```

若在宿主机上操作，对应路径一般为 `<AstrBot数据目录>/plugins/astrbot_plugin_quick_decision`。

本插件不需要安装 `requirements.txt`。表情包功能依赖上述市场插件。

## 配置说明

可在 WebUI 官方插件配置中修改，也可在插件详情页的「判断配置」里用表单编辑自定义上下文和判断问题。两处读写的是同一份官方配置，不是两套存储。

常用项如下（均为建议默认值，可按环境调整）：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 启用快速决策 | 开 | 关闭后不再判断或主动发言，指令和网页判断配置仍可用 |
| 试运行模式 | 关 | 只记录决策，不向 QQ 发送 |
| 判断提供商 ID | 空 | 空则使用默认判断提供商 |
| （已停用）原自动描述视觉提供商 ID | 空 | 1.2.0 起不再使用，保留配置键以免覆盖已有设置 |
| 判断选项生效阈值 | 0.5 | 选中项概率低于阈值则视为不发言或不配图；也可改为文档示例中的 0.7。自定义选择题不使用该阈值 |
| 判断选项温度 | 0 | 0 保持确定性，自定义权重生效时取加权后最高项；大于 0 按温度采样。1 按加权概率采样，小于 1 更集中，大于 1 更随机。适用于选择题和自定义是否题；只影响本插件选择结果 |
| 判断上下文最近消息条数 | 20 | 只用于判断模型的精简上下文 |
| 决策前合并消息等待秒数 | 1.5 | 短时间内连续消息先合并再判断一次 |
| 同一会话冷却时间 | 300 秒 | 刚发过言后，限制群聊插话和冷场主动发言。被 @ / 引用的群聊以及私聊被动回复不受限制 |
| 群聊插话 / 群聊冷场主动 | 开 / 开 | 可分开关闭 |
| 判断发言后直接在群里发送 | 开 | 打开后群聊发言不引用某一条消息；关闭则恢复引用 |
| 群聊冷场时长 | 600 秒（10 分钟） | 到期只评估一次 |
| 私聊冷场主动 / 时长 | 开 / 1800 秒（30 分钟） | 到期只评估一次 |
| 每会话每小时主动上限 | 3 次 | 仅统计冷场后的主动开口 |
| 判断模型自定义上下文 | 空 | 仅注入判断模型，不传给会话模型 |
| 自定义判断问题（JSON） | 默认长短问题 | 官方配置里以 JSON 文本保存。JSON 无效时会记录警告并回退到默认长短问题 |

插件**不会**自动打开官方概率主动回复。

### 温度与选项权重

在插件设置中调整「判断选项温度」，在插件详情页「判断配置」中调整每个自定义选项的「权重」。权重范围为 `0–100`，默认 `1`；大于 `1` 更偏向该项，小于 `1` 减少该项机会，`0` 禁用该项。同一题至少保留一个正权重。选择题在 JSON 的每个 `options` 元素中填写 `weight`，是否题使用 `true_weight` 和 `false_weight`。旧配置缺少这些字段时自动按 `1` 处理。

例如，模型认为 `short` 为 70%、`long` 为 30%，将两者权重分别设为 `1` 和 `3`。温度为 `1` 时，最终抽中 `long` 的概率约为 56.25%；温度为 `0` 时，会确定选择加权后更高的 `long`。正温度下的采样权重为 `(模型概率 × 选项权重)^(1 / 温度)`，归一化后随机选择；模型概率为 `0` 的选项仍不会被选中。

独立权重只用于自定义问题，不会写入判断模型提示。所有权重为 `1` 且温度为 `0` 时保持旧行为。内置发言、选图结果仍需通过原始概率阈值，采样不会绕过阈值；「是否配表情」仍按原阈值判断。决策日志的原始数据会保留模型原选、调整后的分布和实际选项，便于核对。

### 自定义判断问题

默认包含一个可编辑的长短问题，用词与 1.0 相同：

- 判断标准：`如果发言，回复应该简短还是稍详细？`
- `short`：`简短回复，一两句即可`；告诉会话模型：`本轮回复策略：请给出简短、自然的回复，一两句即可。`
- `long`：`更完整、稍详细的回复`；告诉会话模型：`本轮回复策略：请给出稍详细、完整的回复，但仍保持自然。`

你可以修改这些文案，停用或删除该问题，也可以增加其它问题（例如语气、是否追问）。问题类型支持：

- `choice`：至少两个选项。每个选项有 id、写给判断模型的标准、选择权重，以及可选的会话提示。
- `boolean`：是否题，可分别填写「是」或「否」的权重和会话提示。

某个结果的会话提示留空，则该结果不告知会话模型。判断完成后，所有非空提示会按问题顺序拼接，写入本轮临时的 `<quick_decision>` 提示。

自定义问题不得使用保留 id：`action`、`target_message_id`、`use_meme`、`meme_id`。若问题 id 仍为 `length` 且选项为 `short` / `long`，日志和 `/decision status` 会继续显示长度字段，以保持兼容。

## 可选依赖：表情包管理器

如需配表情包，请安装并启用市场插件「表情包管理器」：[`anka-afk/astrbot_plugin_meme_manager`](https://github.com/anka-afk/astrbot_plugin_meme_manager)。图库、分类、逐图描述和导入导出都在该插件的页面中完成。仅使用文字回复时可跳过。

本插件启动后会只读扫描其数据目录（`data/plugin_data/meme_manager/`）中已启用图包的 `semantic_metadata.json`，把每张图的描述交给判断模型。若管理器未安装、未加载或数据不可用，本插件会记录明确提示并只发送文字。

如果本机仍保留 1.1.x 自制图库（`data/plugin_data/astrbot_plugin_quick_decision/memes.json` 与 `memes/`），首次启动会在可验证保留原描述的前提下，将其导入为一个新的图包（默认 id：`quick-decision-legacy`），不覆盖管理器已有图包，也不删除旧文件。迁移记录见同目录下的 `meme_manager_migration.json`，可用于回滚本次新增的图包注册，旧库始终保留。

请在表情包管理器设置中做如下最小调整，避免和本插件同时发图：

- 关闭「启用主动发送表情工具」（`generation.emotion.send_tool_enabled`）
- 将「表情发送概率」设为 0（`generation.emotion.probability`）

不要改判断模型或主模型提供商等其他配置。

## 管理员指令

仅 AstrBot 管理员可用（`@filter.permission_type(ADMIN)`）。

- `/decision status`：查看当前会话最近一次决策、判断阈值，以及表情包管理器对接状态。自制图库的 `/meme` 管理指令已移除。

## 网页管理

在 WebUI 登录 Dashboard 后，打开本插件详情页：

- 「判断配置」：查看表情包管理器对接状态；编辑判断模型自定义上下文，以及自定义判断问题（含选项标准、是否启用、告诉会话模型的提示）。保存后写入官方插件配置（`data/config/astrbot_plugin_quick_decision_config.json`），与设置页是同一份数据。
- 「决策日志」：查看最近的判断结果。

表情图库改由「表情包管理器」保存。本插件数据目录（`data/plugin_data/astrbot_plugin_quick_decision/`）仍保存决策日志和旧自制库备份，不会写进插件代码目录。内存中的会话缓冲会在重启后丢失，这是预期行为。

## 决策失败时的降级

判断提供商未配置、超时、HTTP 错误或返回非法结果时会捕获 `DecisionError`：

- 群聊被动回复、群聊插话、以及所有主动发言：**不发送**。
- 私聊被动回复：退回纯文字，放行官方 LLM，不配图。

若判断要配图但表情包管理器不可用、没有合适图片、文件缺失或发送失败，退回纯文字，不会额外补一句说明，也不会改用旧自制图库。

## 注意事项

- 需要 AstrBot `>=4.29.4,<5`。
- 官方人格、Skill 和聊天记录只作用于文字生成，不进入判断模型的 `state`。判断模型自定义上下文同样不会进入会话模型。
- 冷场主动开口在没有入站事件时，仍会读取官方会话管理器中的历史和人格后自行调用聊天模型，再通过 `send_message` 发出。该路径尽量保留人设与历史，但尚未完整复用官方主 Agent（工具循环、压缩、after-send 等）。官方流式回复下的独立表情与 regex 分段也尚未适配。
- 不要和官方主动回复同时开启，以免重复说话。
- 不要同时让表情包管理器自动配图或通过 `send_meme` 工具发图，以免和本插件各发一张。
